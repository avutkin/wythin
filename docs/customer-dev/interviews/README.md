# Interviews

One file per conversation: `YYYY-MM-DD-first-last.md`. Structure each file as:

1. **Summary** (written after): who, how long, what they use the app for, what they value, what frustrates them, three quotes, what we promised them.
2. **Feedback items** as a bullet list, each also copied to `../feedback-log.md` and the person's file.
3. **Raw transcript** from Zoom, unedited, at the bottom.

Zoom transcripts pasted into the session get filed here by Claude.
