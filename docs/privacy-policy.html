Purposes and permissions

Local sensor processing, cloud history, full raw archiving, coaching access and external AI are different purposes. The proposed release must explain and obtain each required permission before the relevant operation. A required contract checkbox is not a universal privacy permission. Required processing must be necessary to the specific service you request; unrelated research or future analytical flexibility must not silently inherit that justification.

We do not authorize new research, model training, advertising or unrelated secondary use through this notice. If a new purpose is proposed, it requires assessment, appropriate notice and any legally required separate consent. An inferred state or summary is still health information when linked to a person.

Recipients and processing locations

Hetzner: Wythin's current cloud server is hosted in Finland. Data uploaded for cloud features includes the records needed for those features and is transmitted over HTTPS. A private Object Storage bucket has been provisioned in Helsinki, but is not connected to production recording. Archive encryption has passed a synthetic storage check. A separate encrypted backup in Germany is configured; restoration of the production database and a synthetic signal has been verified. The applicable provider retention, permitted uses and subprocessors must be established before release; this draft does not promise zero retention or training exclusions that have not been verified.

Your selected integrations: a personal API or MCP access token authorizes the scope available to its holder. We may disclose information where legally required, to address a valid legal request, or to protect rights and security within applicable law. Storage, retention and deletion

Measurements and history can be stored on your device and, when the relevant cloud feature is enabled, on Wythin's server. Current stored records are retained until deletion. This is not a justification for indefinite retention: the proposed release must set and apply periods or objective criteria for each purpose. There is no implemented rule that deletes or compacts raw recordings after 30 days. Compression does not remove personal-data obligations.

Turning a transfer control off stops the associated future operation only once that control is implemented and enforced; it does not itself erase past copies. The current cloud-data deletion operation removes specified uploaded datasets, but user/token records and a minimal disabled-consent marker can remain. Uninstalling the app does not delete cloud records. Full account erasure, recipient notification, backup expiry and restoration-safe deletion remain release requirements, so this draft does not claim they are complete.

For an access, correction, deletion, withdrawal or account-erasure request, contact us using the route below. We must explain any legally justified retention, its purpose and duration. Any exception is limited to what the law permits. Data in backups must be handled within applicable deadlines and protected from returning to active use after deletion.
